ثلاث طبقات، ومسؤول واحد

معظم عملي كان امتلاكًا كاملًا للمنتج، لا جزءًا صغيرًا من نظام يملكه غيري.

Flutter متعدد المنصات

قاعدة شيفرة Dart واحدة لـ iOS وAndroid وmacOS وWindows والويب. عمل دون اتصال عبر Drift وSQLite وHive مع مزامنة فورية ومعالجة للتعارضات — إضافة إلى إضافات أصلية وأدوات للشاشة الرئيسية بـ Kotlin وSwift حين تتطلّب المنصة ذلك.

الخوادم ونمذجة البيانات

واجهات برمجية بـ Dart/Serverpod وLaravel فوق PostgreSQL وMySQL. أنظمة SaaS متعددة المستأجرين بأمان على مستوى الصفوف وأقل الصلاحيات، ومصادقة JWT مع رموز التحديث، وتصميم قواعد بيانات يصمد أمام دفتر قيد مزدوج مع إعادة تقييم العملات.

الإطلاق والبنية التحتية

Docker وFly.io وCloudflare وخطوط CI/CD عبر GitHub Actions. خطوط إصدار متعددة المنصات، وتوقيع الشيفرة، والروابط العميقة — النصف غير اللامع من العمل الذي يقرّر إن كان المنتج سيصل إلى المستخدم أصلًا.
